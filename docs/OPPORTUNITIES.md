# 独立机会与策略触发口径

综合观察按上海日期、股票、BUY/SELL 方向分组。原始 PostgreSQL 与 SQLite 信号不删除、不改写。每组最早触发的价格、时间、数量、环境与观察记录为综合参考，不把后续策略的价格或样本并入第一条记录，不累加数量，不代表实际成交。最早没有观察数据时保持缺失，不拿后续策略填补。

`/signals` 默认请求 `/api/signals?view=opportunities`，每组一行，可展开独立策略触发时间与价格；K线标记也使用分组结果。API 默认不带 view 时仍返回原始记录，保留兼容性。状态不一致标记 MIXED，不将执行次数、成交数量折叠改写。顶部统计采用机会口径，strategy_stats 仍是各策略原始触发数量；raw_signal_count 单列。统计窗口为有限记录，不宣称全库总数。

`/signal-review` 每个机会仅一行，默认参考最早信号。最近变化是该信号最近观察日末笔样本相对参考价的变化，极值只取其已采集的观察记录。展开逐策略、逐日显示各自独立价格变化，不计算组合交易收益或胜率。接口保留 signals，新增 opportunities 与 summary；先选最近 100 个完整机会，再取所有组成员，避免一条信号被分页截掉导致基准改变。

实际股票名称仍来自统一解析；使用 DOM textContent 输出展开详情，避免名称或策略文本被解释为 HTML。主列表扩展字段经转义。
