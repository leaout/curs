# 连板接力增强：规划与第一版

KOL 辅助对照已接入，详见 [KOL 接力说明](KOL_RELAY.md)。保留原接力状态，仅附加按当时已知发言形成的影子结果，不替换风险判断。

目标是检验接力是否优于现有首板，而非预设成功率更高。保留原策略，禁止实盘。

第一阶段（本版）：昨日固定完整涨停名单按一进二、二进三、高位接力分组，结合既有全市场快照记录环境、封板采样及明确题材合力，只输出影子状态。

第二阶段：核实题材分组日期，完善同梯队相对强度、累计涨幅与分歧承接。不会将最早涨停直接认定为龙头，不把盘后龙虎榜当盘中信息。

第三阶段：按同交易日同梯队，对照原策略与过滤结果的次日收益、最大不利波动、盈亏比、漏掉的上涨和可成交性。没有排队数据不假定涨停价成交。

## 已实现规则

沿用情绪采集器按前一交易日确定的 finalized 涨停名单和全市场行情，不额外拉取数据。第一版只评估非风险警示10%涨停证券。当日新鲜行情、完整市场覆盖是前提。昨日涨停负溢价且至少20%样本跌幅达5%，或已判退潮，则不通过。

至少三个递增时间戳样本，跨度240秒，封板且成交额增加。重复时间戳不计数；间隔超过180秒、成交额倒退或覆盖不足时重置连续确认。观察到两次开板、一字状态均不通过。两分钟采样会漏掉短暂开板，不能称为连续真实封单或实际全部开板次数；采样中断后重新计数。

`market_sentiment.relay.groups` 需要人工核实的题材成员代码，至少另两个新鲜成员上涨3%以上。默认分组为空，因此题材未知，不通过。禁止以整个观察池代替题材。`enabled: false` 可停止影子采集。

结果仅为待观察或影子条件通过，不触发原策略、不记录买单，不判断主线或龙头。本版没有盘口队列、竞价承接、流通换手率或退出策略。

## 存储与展示

沿用信号 SQLite，表 `relay_observations` 按时间和代码幂等保存完整 JSON 依据、昨日日期、股票名、梯队与规则版本。已有 `/market-sentiment` 页面显示最新一批；API 同页数据增加 `relay`。历史不删除，供后续对照。无昨日完整名单不造候选，周末不制造快照；页面明确提示核对时间。不是当前买入建议。
