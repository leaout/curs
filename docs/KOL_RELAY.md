# KOL 接力辅助判断第一版

目标是验证公开观点对原接力候选是否有增量筛选价值，不做跟单、荐股或自动交易。原离线研究入口保持独立；运行链路不加载 FinBERT 权重或计算模拟收益。

## 数据与导入

准备 UTF-8 CSV，必需列为 `author,source_url,published_at,stock_code,text`。发布时间必须带时区（例如 `2026-10-26T09:00:00+08:00`），股票使用 `600001.SH` 形式。原文必须 HTTPS，无账号密码；导入不请求链接，真实性和作者身份需人工核实。一个股票一行，禁止把未明确关联的股票随意附加到发言。系统不自动抓雪球或其他平台。

执行：

```powershell
.venv\Scripts\python.exe -m curs.kol_intent.relay_context 路径\posts.csv
```

所有行先验证再入库；默认信号 SQLite 中新增 `kol_public_posts`。首次本地采集时间取实际导入时间，不接受 CSV 回填。重复导入不改首次时间；相同原文的编辑版本作为新记录，不能覆盖旧证据。原文、作者、明确股票与时间一起留档。导入不是公开发布，不会创建买单。数据库包含用户输入，请勿提交 Git。

## 判断与对照

`market_sentiment.relay.kol_context` 默认 `enabled: true, lookback_hours: 48`，最大支持168小时。每次接力快照只允许发布时间和首次导入时间都严格早于候选时刻，且发布时间在观察窗内。同股票才匹配。对照证据随候选 JSON 固定保存，不在页面读取时重新计算历史判断。

规则先排除否定、条件/疑问、转述、回顾晒单、持仓披露，然后复用原模块明确多空关键词。没有模型置信度或作者胜率评分。文本规则不懂所有语义，可能漏判或误判；不是人工认证的事实。

每作者取窗口内最新明确方向，忽略非方向文本；相同规范化文本跨作者只计一次，防止简单复制放大权重。这不代表能识别同一作者的多账号、近义转述或真实独立意见。后续出现中性文字不自动撤销旧明确方向，旧观点直到过期仍可能有效，需人工关注。

有反对方向标“明确分歧”（包括只有反对的情况）；只有支持方向标“明确支持”；其余“无有效信息”。窗口内全文数量、非方向排除数、支持/反对计数、最多十条代表依据均保留。作者、URL、原词、发布时间与首次导入时间在原市场情绪页展示，文本安全渲染为纯文字。

原 `status` 和风险原因永远保留。无信息不否决，支持不覆盖风险。只有原影子条件已通过且存在明确分歧时，`kol_shadow_status` 为“分歧待复核”。异常标数据不可用，原流程继续。此字段不改变交易事件、不产生订单。接力模块关闭时不采集；KOL开关关闭时保留原接力观察。

## 后续验证

先积累可靠数据，按同交易日同梯队比较有/无支持、分歧与无信息的次日表现、最大不利波动和覆盖率。不能因过滤减少亏损样本就宣称提升胜率，必须同时统计漏掉的好机会、作者选择偏差及不可成交情况。只有证明稳定增益后才讨论正式过滤。
